# Contributing to Credit Risk Prediction Project

We welcome contributions to this project! By participating, you agree to abide by our Code of Conduct.

## How to Contribute

There are several ways you can contribute to this project:

*   **Report Bugs:** If you find a bug, please open an issue on GitHub.
*   **Suggest Enhancements:** Have an idea for a new feature or improvement? Open an issue to discuss it.
*   **Submit Pull Requests:** If you've fixed a bug or implemented a new feature, we encourage you to submit a pull request.

## Code of Conduct

Our project adheres to a Code of Conduct. Please review it to understand the expected behavior and reporting procedures.

## Reporting Bugs

When reporting a bug, please include:

*   A clear and concise description of the bug.
*   Steps to reproduce the behavior.
*   Expected behavior.
*   Screenshots or error messages, if applicable.
*   Your operating system and Python version.

## Suggesting Enhancements

When suggesting an enhancement, please include:

*   A clear and concise description of the proposed feature.
*   Why this feature would be beneficial to the project.
*   Any potential challenges or considerations.

## Pull Request Guidelines

Before submitting a pull request, please ensure the following:

1.  **Fork the repository** and create your branch from `main`.
2.  **Install dependencies:** Ensure you have all necessary dependencies installed (see `requirements.txt`).
3.  **Code Style:** Adhere to PEP 8 guidelines for Python code.
4.  **Tests:** If you've added new features or fixed bugs, please include appropriate unit tests.
5.  **Documentation:** Update relevant documentation for any changes you've made.
6.  **Commit Messages:** Write clear and concise commit messages.
7.  **Rebase:** Rebase your branch on `main` before submitting to avoid merge conflicts.
8.  **One Feature/Bug per PR:** Each pull request should address a single feature or bug fix.

Thank you for contributing to the Credit Risk Prediction Project!
